Engineering Architecture & Methodology

How GestureConnect Works

GestureConnect bridges the communication divide for hearing-impaired communities by translating English and Marathi text and speech into Indian Sign Language (ISL/MSL) using a decoupled 3D humanoid avatar.

8-Stage Technical Flow

End-to-End System Pipeline

From natural language acquisition to 3D avatar keyframe execution in under 45 milliseconds.

01
1. User Input

Accepts spoken voice via microphone or typed text in either English or Marathi Devanagari script.

02
2. Speech Recognition

Web Speech API converts acoustic audio streams into normalized UTF-8 text representation with real-time transcription.

03
3. Language Detection

Script-level Unicode inspection differentiates Devanagari vs Latin characters to route pipeline logic appropriately.

04
4. NLP Preprocessing

Performs Unicode NFC normalization, punctuation filtering, stopword handling, and morphological tokenization.

05
5. 5-Tier Sign Mapping

Hierarchical resolution: Phrases → Exact words → Normalized stems → Synonyms → Fingerspelling fallback.

06
6. Canonical Sign IDs

Standardized tokens (e.g. SIGN_MOTHER, SIGN_WATER) bridge language logic to visual animation assets.

07
7. 3D Avatar Rendering

Blender humanoid avatar (slaygurl.glb asset layer) keyframes arm, hand, finger, and facial posture smoothly.

08
8. ISL Sequence Output

Sentence-level seamless playback delivers natural Indian Sign Language communication to the user in real time.

Our Vision & Problem Statement

Over 63 million individuals in India experience significant auditory impairment. In regional settings across Maharashtra, access to certified bilingual Marathi & English sign language interpreters is critically limited in public transit, hospitals, educational institutions, and civic services.

GestureConnect addresses this challenge with an accessible web-based translation platform. Rather than requiring bulky sensor gloves or proprietary hardware, any user with a smartphone or laptop can speak or type in English or Marathi and receive immediate, grammatically aligned Indian Sign Language output via an expressive 3D humanoid avatar.

Key Engineering Innovations
  • Bilingual Convergence: Both English and Marathi inputs converge into unified canonical linguistic representations.
  • Zero-Loss Fingerspelling Fallback: Out-of-vocabulary words are never dropped; they decompose into character-level sign animations.
  • Offline Authoring, Instant Web Execution: 3D keyframe animations authored in Blender run seamlessly via web-native video playback without heavy GPU requirements.
